## Setting up Cloudflare (your part, about 15 minutes)

You need four GitHub secrets: two to create the site, two to protect it. Add them in this order, so nothing is ever public.

1. **API token:** Cloudflare dashboard, then My Profile, then API Tokens, then Create Token, then Custom token.
   - Permission: Account, Cloudflare Pages, Edit. Limit it to your account.
   - Save it as the GitHub secret `CLOUDFLARE_API_TOKEN`.
2. **Account ID:** shown on the Workers & Pages overview page. Save it as `CLOUDFLARE_ACCOUNT_ID`.
3. **Create the project:** run the `site-deploy` workflow (Actions, then site-deploy, then Run workflow).
   - With only those two secrets, it creates the Pages project (done 2026-10-29) but doesn't publish anything yet.
   - **The address:** Cloudflare dashboard, then Workers & Pages, then the `stockwatch` project, then Custom domains / Domains. It's usually `stockwatch.pages.dev`, or that with a suffix if the name was taken. GitHub hides it in the run log, because the name matches a secret.
4. **Access:** Cloudflare Zero Trust (it asks for a team name the first time; the free plan covers this). Then Access, then Applications, then Add an application, then Self-hosted.
   - **Domains:** the address from step 3, and a second one for previews, `*.` plus that address.
   - **Policy:** Allow, Include, Emails, your email.
   - **Login method:** One-time PIN.
   - Save it, then copy the **Application Audience (AUD) tag**.
5. **Access secrets:**
   - `ACCESS_AUD`: the tag from step 4.
   - `ACCESS_TEAM_DOMAIN`: your team name plus `.cloudflareaccess.com`.
6. **First real deploy:** run `site-deploy` again. Now it publishes. After that, the nightly redeploys every night.
7. **Check it:** open the address on your phone. You should get the one-time-code login, then the Today screen.

**Not verified yet:** the plan lists "whether Access needs an owned domain". Cloudflare documents protecting a `pages.dev` address with a self-hosted Access app, which is what step 4 does. If it refuses, the fallback is a cheap domain (about $10 a year, in the plan's budget).
